# Security Policy

## Security boundary

Workspace Tabs is a local Omarchy and Quickshell bar widget. It reads workspace and window metadata exposed by Hyprland and runs one workspace-focus command through Omarchy's bar API.

The plugin does not require or read:

- API keys, access tokens, passwords, or credentials
- Environment files or keyrings
- Browser profiles, cookies, messages, or application databases
- Network services, analytics, or telemetry

The plugin does not launch applications, start background services, move windows automatically, or send data off the computer.

## Reporting a vulnerability

Use the repository's **Security** tab and choose **Report a vulnerability**. Do not place keys, credentials, exploit details, or private system information in a public issue.

## Supported version

Security fixes apply to the latest version on the default branch.
